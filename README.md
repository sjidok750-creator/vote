# 🔒 비밀투표 · VoteSecret

링크 하나로 **익명 투표**를 진행하고, **결과는 관리자만** 볼 수 있는 모바일 PWA 투표 앱.
설치 없이 iOS·안드로이드 브라우저에서 바로 동작하며, "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## ✨ 핵심 기능

- **관리자**가 제목·항목·설정을 만들고 **공유 링크**를 받습니다.
- **참여자**는 링크에 접속해 **투표만** 합니다. 결과는 보이지 않고, 투표 후 완료 화면으로 빠져나갑니다.
- **재방문 차단**: 한 번 투표한 기기는 다시 투표할 수 없습니다(설정에 따라).
- **결과는 관리자 전용 링크**로만 확인 — 도넛+막대 그래프 · CSV · 결과 이미지 저장.
- **완전 익명**: 누가 무엇을 골랐는지 저장하지 않습니다(중복 판별용 해시값만 보관).
- **카카오톡 공유 최적화**: 링크를 보내면 **투표용지 모양 미리보기 이미지**가 자동으로 표시됩니다.
- **결과 공유**: 원할 때 결과 페이지를 공개하거나, 결과를 **그래프 이미지**로 저장·공유할 수 있습니다.

## 📱 카카오톡 공유

- 투표/결과 링크를 카카오톡에 붙여넣으면 **OG 미리보기**가 뜹니다.
  투표 링크는 **연한 파랑 투표용지 카드**(`/v/[slug]/opengraph-image`), 결과 링크는 **그래프 카드**로 보입니다.
  별도 설정 없이 동작합니다.
- 더 예쁜 **카카오톡 피드 카드 + [투표하기] 버튼**으로 보내려면 `NEXT_PUBLIC_KAKAO_JS_KEY`(카카오 JavaScript 키)를
  설정하세요. 키가 없으면 휴대폰 기본 공유 시트/링크 복사로 자동 폴백합니다.
  ([카카오 개발자 콘솔](https://developers.kakao.com)에서 키 발급 후, 플랫폼 ▸ Web 도메인에 배포 주소 등록)

## ⚙️ 관리자 설정

| 설정 | 내용 |
|---|---|
| 중복투표 방지 | `기기 기준`(추천) · `IP 기준` · `엄격(기기+IP)` · `중복 허용` |
| 선택 방식 | 단일 선택 / 복수 선택(최대 개수 지정) |
| 결과 공개 | 투표자에게 결과 공개 여부 (기본 **비공개**) |
| 마감 | 마감 시간 예약 또는 수동 마감/재개 |
| 관리 | 표 초기화 · 투표 삭제 |

## 🧭 사용 흐름

1. 첫 화면(`/`)에서 투표를 만들고 **「투표 만들고 링크 받기」** 클릭
2. 두 개의 링크를 받습니다
   - 📣 **참여 링크** (`/v/...`) — 사람들에게 공유 (QR 코드 제공)
   - 🔑 **관리자 링크** (`/r/...`) — **본인만 보관**, 결과 확인용
3. 참여자는 투표 → "투표 완료" 화면. 같은 기기로 재접속하면 "이미 참여하셨습니다".

> ⚠️ 관리자 링크는 결과를 볼 수 있는 열쇠입니다. 외부에 노출되지 않게 보관하세요.

## 🛠 기술 스택

Next.js 16 (App Router) · TypeScript · Tailwind CSS · Prisma + PostgreSQL · PWA

## 💻 로컬 실행

PostgreSQL 한 개가 필요합니다. (로컬은 Docker로 간단히: `docker run -e POSTGRES_PASSWORD=pw -p 5432:5432 -d postgres`)

```bash
npm install
cp .env.example .env          # DATABASE_URL 을 본인 Postgres 주소로 설정
npm run db:deploy             # 스키마 동기화(prisma db push)
npm run dev                   # http://localhost:3000
```

## 🚀 배포 (Render — 추천, 무료)

이 저장소에는 `Dockerfile`과 `render.yaml`이 포함되어 있어 **자동 배포**됩니다.

1. [render.com](https://render.com) 가입 후 **New ▸ Blueprint** 선택
2. 이 GitHub 저장소(브랜치 `main`)를 연결하면 `render.yaml`이 자동 적용됩니다
   - **무료 PostgreSQL** 데이터베이스가 함께 생성되어 자동 연결됩니다 (무료 플랜은 영구 디스크 미지원이라 DB로 데이터를 보존)
   - `VOTE_SALT`는 자동으로 안전한 값이 생성됩니다
3. 배포가 끝나면 `https://...onrender.com` 주소가 발급됩니다 → **이 주소를 공유**하세요

> Railway·Fly.io 등 Docker를 지원하는 어떤 플랫폼에서도 동일하게 동작합니다.

### 환경 변수

| 변수 | 설명 |
|---|---|
| `DATABASE_URL` | PostgreSQL 접속 주소 (Render Blueprint 가 자동 주입) |
| `VOTE_SALT` | 익명 해시용 비밀 솔트 (긴 임의 문자열 권장) |

## 🔐 익명성 & 중복방지에 대하여

- 투표 기록에는 선택한 항목만 남고, **개인 식별 정보는 저장하지 않습니다.**
- 중복 판별을 위해 기기 ID와 IP는 **단방향 해시(SHA-256 + 솔트)** 로만 보관합니다.
- `기기 기준` 방식은 사용 편의가 가장 좋지만, 사용자가 브라우저 데이터를 완전히 지우거나
  다른 기기/시크릿 모드를 쓰면 우회될 수 있습니다. 더 엄격히 막으려면 `엄격(기기+IP)` 또는
  네트워크 환경에 맞춰 `IP 기준`을 선택하세요.
